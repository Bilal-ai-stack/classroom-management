The Sovereign & Offline-First Manifesto

Most educational software forces schools into expensive cloud subscriptions, vendor lock-in, and unpredictable privacy liabilities. ClassroomOS is architected from the ground up to respect school sovereignty:

Zero Cloud Requirement

Runs as a self-contained desktop service. No external Python or Node.js runtime needed. The software operates reliably even during complete campus internet outages.

Absolute Privacy by Design

Student names, attendance records, guardian details, and audit trails remain strictly inside %LOCALAPPDATA%\ClassroomOS on your institutional hardware.

Transparent SQLite Storage

No proprietary binary blobs or obscure database servers. Standard SQLite database with transactional ACID migrations and verified file-level snapshots.

Frequently Asked Questions

Common questions about deployment, data security, and operational workflows.

Does ClassroomOS require an active internet connection?

No. ClassroomOS is a 100% local-first application. Attendance tracking, student portfolios, photo-assisted counting, database backups, and reports run entirely on your local workstation without network connectivity.

Where are student and attendance records stored?

All database tables, student photos, and administrative logs are saved locally in %LOCALAPPDATA%\ClassroomOS\data. No records are sent to external cloud servers or third parties.

Does ClassroomOS store facial recognition biometric data?

No. The photo attendance assistant uses standard OpenCV Haar Cascade object detection to count faces in classroom snapshots. No facial embeddings, biometric markers, or identity templates are ever computed or stored.

How do Guardian WhatsApp notifications work?

Authorized educators can click Send WhatsApp on any student record to launch a pre-formatted message in WhatsApp Web or Desktop via secure wa.me deep links. For larger institutions, optional automated Cloud API dispatch is available.

How do I upgrade from v2.0.0 to v2.1.0?

Simply download and run ClassroomOS-Setup-2.1.0.exe. The installer automatically updates application binaries while preserving your existing database and school records in AppData. Automatic database migration 6 seamlessly applies all new fields.
